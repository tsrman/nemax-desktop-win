Неофициальный клиент для мессенджера MAX. Это оболочка для `web.max.ru`, которая фильтрует лишние запросы и блокирует телеметрию. 

## Особенности

* **Блокировка аналитики.** Запросы к трекерам режутся на лету (правила лежат в `data/blocklist.txt` и обрабатываются через `filter.js`).
* **Подмена User-Agent.** Встроенный генератор каждый раз отдает разные юзер-агенты из списка (`data/useragents.txt`).
* **Кросплатформенный (Windows/Linux).** Работает через нативный WebView системы.

## Сборка из исходников

Для компиляции нужен установленный [Rust](https://rustup.rs/). 

**Важно по Linux:** клиент нормально работает, только если собрать его прямо на той системе, где вы будете им пользоваться. Переносить готовый бинарник на другую машину не стоит — скорее всего, всё сломается из-за разницы в системных библиотеках.

Для сборки под Linux предварительно нужно поставить зависимости для WebKit:
```
sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev
```

Клонируйте репозиторий и запустите сборку:

```
git clone https://github.com/nemax-dev/nemax-desktop.git
cd nemax-desktop
cargo build --release
```

Готовый бинарник появится в папке `target/release/`.

## Отказ от ответственности

Я не связан с разработчиками мессенджера MAX. Проект написан для личного использования. Если API веб-версии изменится, фильтры могут сломаться.

## Про лицензию и использование кода

Я выложил исходники в первую очередь для того, чтобы вы могли провести аудит кода и убедиться: программа делает ровно то, что заявлено — режет трекеры и не трогает ваши данные. 

**Важный момент:** Пожалуйста, не нужно просто клонировать этот репозиторий, менять мою ссылку на донат на свою и перевыпускать клиент под своим именем. Это как минимум неэтично. 

Если у вас есть идеи, как сделать клиент лучше — велком в Issues или Pull Requests. Я за любое адекватное развитие проекта, но против тупого копипаста ради наживы.
