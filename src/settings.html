Фильтрация
Service Workers
По умолчанию отключены для защиты приватности.
Включение может потребоваться для корректной работы сайта.
Изменение вступит в силу после перезапуска приложения.
Системный трей
Сворачивать в трей
При сворачивании окна прятать его в системный трей вместо панели задач.
Закрывать в трей
При нажатии на «×» окно скрывается в трей. Полный выход — через меню трея.
Запускать свёрнутым
При запуске приложение не показывает окно, только иконку в трее.
Автозапуск (Windows)
Автоматически запускать neMAX при входе в систему (свёрнуто в трей).

DevTools

В подавляющем большинстве случаев не требуется.
